THE BASICS

What is an AI coding agent?

An AI coding agent can work with project files and use tools to help plan, edit, and review code. The useful question is how it fits into your workflow: which model it uses, what actions it can take, and how you check the result.

These videos cover both the first setup and the pieces behind more capable agents. Start with a tool you can run, then explore skills, MCP connections, instruction files, and review workflows.

Free model availability, limits, and pricing can change. Check each provider's current terms before choosing a setup.
